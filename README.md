# Happy Birthday, Lidiya!

A small, responsive birthday greeting page made for Lidiya. It features a hand-styled birthday cake, a personal note, birthday wishes, and a confetti effect when the **Make a wish** button is clicked.

## Open the page

No build tools or dependencies are required. Open `index.html` in a modern web browser.

## Project files

- `index.html` — page content and birthday message
- `style.css` — layout, colors, cake illustration, and responsive styling
- `script.js` — confetti and button interaction

## Customize

Edit the text in `index.html` to change the name, birthday greeting, personal note, and wishes. Adjust the visual design in `style.css` or the button interaction and confetti in `script.js`.
